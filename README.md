# For Now: *A good place to stop.*

UC Design Industry Studio · Break / Make, UC Design + Miko Designs.

> "What would a feed look like if helping people finish were part of good design?"

For Now presents short videos in small, finite collections. At the end of a collection you can finish watching, or deliberately open another one, with its topic, clip count and length shown first. Finishing stops playback and shows "Finished for now." You can go back to where you were, paused, or start a new visit. Nothing plays or loads on its own.

This is a student concept prototype for critique and exhibition, not a finished product. All footage is self-shot by the project team.

## View it

- **Online:** <https://alekozf.github.io/For_Now/> (once GitHub Pages is turned on: **Settings → Pages → Deploy from a branch → `main` / `(root)`**). The root `index.html` redirects to `app/`.
- **From disk:** open `app/index.html` in Chrome.
- **Local server:** from this folder, run `python -m http.server 8000`, then visit <http://localhost:8000/app/>.

No install or build step. Plain HTML, CSS and JavaScript.
